# Prompt Examples

## Upgrade existing UI

```text
Use the Roblox UI skill.

Inspect the existing interface first and preserve all working functionality. Then improve hierarchy, spacing, icons, responsiveness, and interaction feedback.

Do not replace it with generic AI-looking cards. Keep the game's identity and make the result clearly better on PC, mobile, and console.
```

## Cartoon game

```text
Use the Roblox UI skill with the cartoon preset.

Upgrade the lobby UI to feel like a polished cartoon multiplayer brawler. Keep gameplay clear, use stronger silhouettes and icons, and add short responsive animations.

Preserve all existing buttons and scripts.
```

## Debug pass

```text
Use the Roblox UI skill and audit the entire interface.

Fix clipping, bad AnchorPoints, inconsistent spacing, mobile overflow, text sizing, ZIndex issues, controller navigation, and conflicting tweens before changing the visuals.
```

## Mobile + console

```text
Use the Roblox UI skill.

Keep the desktop identity, but create a proper mobile and console pass. Do not simply shrink the desktop UI. Fix touch targets, safe areas, text constraints, scrolling, and gamepad focus states.
```
